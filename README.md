# 📰 ITI Final Project - News Application

## 📜 Overview  
This is my final project for the ITI Summer Training, where I developed a **News Application**. The app features onboarding screens, Firebase authentication for user management, and news data fetched through an API. **GetX** is used for state management to handle app logic efficiently. 

The app has a variety of screens, including:
- A **News Screen** to display the latest news.
- A **Search Screen** to search for news articles based on specific keywords.
- A **Profile Screen** to manage user information.

## ✨ Features  
- 🚀 **Onboarding Screens**: Introduces users to the app and its features.
- 🔐 **Firebase Authentication**: Allows users to sign up, log in, and manage their accounts.
- 🌐 **API Integration**: Fetches news data from an external API to display the latest articles.
- 📰 **News Screen**: Displays a list of news articles with titles, descriptions, and images.
- 🔍 **Search Screen**: Allows users to search for news articles using a specific keyword.
- 👤 **Profile Screen**: Displays user information and allows profile management.

## 🛠️ Technologies Used  
- **Flutter**: Framework used to build the cross-platform app.
- **Dart**: Programming language for Flutter development.
- **Firebase**: For user authentication and data storage.
- **API**: To fetch news data.
- **GetX**: State management solution used to manage app state efficiently.
